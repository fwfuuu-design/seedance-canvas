# Seedance Canvas

一个类似 LibTV 的无限画布，用来调用 [New API](https://github.com/QuantumNous/new-api) 网关里的 **Seedance 2.5 / 2.0** 视频模型：上传参考素材，用连线把提示词和素材接到视频节点上，在节点上选参数生成；所有素材和成片都存进你选的项目文件夹。

- 零依赖：Node 18+ 和浏览器即可，不用 `npm install`
- 本地运行，只监听 127.0.0.1；API Key 只存在你自己的浏览器里

## 快速开始

```bash
git clone https://github.com/fwfuuu-design/seedance-canvas.git
cd seedance-canvas
node server.mjs        # 或 npm start
```

浏览器打开 **http://127.0.0.1:8899**：

1. 欢迎页点「新建项目」或「打开项目文件夹」，在 Finder 里选一个文件夹。选择框弹不出来时，用「手动输入文件夹路径」。
2. 右上角 ⚙ 设置里填**网关地址**和 **API Key**，点「测试连接」。

### 网关要求

- New API 网关，已配置 `doubao-seedance-2-5-260628` / `doubao-seedance-2-0-260128` 渠道
- 网关需要对浏览器放行 CORS（页面直连网关，Key 不经过本地服务）
- 视频接口：`POST /v1/video/generations`，`GET /v1/video/generations/{task_id}`（路径可在设置里改）

## 项目文件夹

一个文件夹就是一个项目：

```
你选的文件夹/
  canvas.json      画布：节点、连线、视口、未完成的任务 ID
  assets.json      资源库索引：提示词、参数、费用、任务 ID
  assets/          所有素材和成片
```

- 只会新增这三样，不动文件夹里原有的文件；整个文件夹拷走就是完整项目。
- 成片生成后立刻下载到 `assets/`。上游的签名链接 24 小时就过期，本地这份不会。

| 新建节点 | 双击空白处 / 右键 / 把文件直接拖进来 |

| 撤销 / 重做 | ⌘Z / ⇧⌘Z |
| 适配视图 | ⌘0 |

## 生成

选中视频节点，下方浮出生成器：

- **模式**：文生视频 / 首帧 / 首尾帧 / 参考生视频，决定连进来的图片当什么用；每张图的用途也可以单独改
- **参数**：模型、比例、分辨率、时长、个数、声音；高级里有返回尾帧、固定镜头、水印、种子、超时
- **提示词**：连进来的文本节点按顺序拼在前面；`@` 引用素材；运镜 / 特效预设；润色、翻译（调用网关里的对话模型）
- **预估金额**：按网关计费系数实时计算

**续写镜头**：上一段开启「返回尾帧」，把它连到下一个视频节点，尾帧就成了下一段的首帧。

**批量生成**：框选多个视频节点后点「批量生成」，最多同时跑 3 个。

**任务不会丢**：任务 ID 一提交就写进 `canvas.json`；刷新、重启、重开项目后，未完成的任务自动接着查。

## 踩过的坑（实测）

- **查询响应带信封**：New API 返回 `{code, data: {status: "SUCCESS", ...}}`，状态是大写。
- **时长要写两处**：doubao 插件只读 `metadata` 里的字段。`duration` 只写顶层会被丢掉，上游回退到「自动」时长（要 4 秒出了 10 秒，按 10 秒计费）。本项目顶层和 `metadata` 都写。
- **请求体上限**：实测网关在 15–20 MB 之间直接断开连接。页面在 14 MB 拦截；图片长边超过 2048 会先压成 JPEG，音频原样发送。
- **参考视频只收公网链接**：本地视频只能预览和存档；本工具生成的视频 24 小时内可直接当参考。
- **档位按像素预算算**：480p 的 16:9 是 854×480，4:3 是 752×560；token ≈ 宽 × 高 × 24 × 秒 ÷ 1024，实测偏差约 0.4%。

## 计费系数（元 / 百万 token）

| 模型 | 分辨率 | 无参考视频 | 含参考视频 |
|---|---|---|---|
| 2.5 | 480p / 720p | 70 | 42 |
| 2.5 | 1080p | 77 | 46 |
| 2.0 | 480p / 720p | 46 | 28 |
| 2.0 | 1080p | 51 | 31 |
| 2.0 | 4k | 26 | 16 |

取自作者所用网关的 `/api/pricing`，不同网关可能不同，改 `lib/seedance.js` 里的 `RATE` 即可。

| 文件 | 说明 |
